🎮 ethycstaMC

Welcome to ethycstaMC! 🚀

A Minecraft: Java Edition launcher for Android based on the amazing work of PojavLauncher ❤️.

---

✨ What's ethycstaMC?

ethycstaMC is a fork of PojavLauncher made for fun, learning, and future improvements. The goal is to build on an already awesome launcher while giving it its own identity. 🌟

⚠️ Currently a work in progress, so expect changes, experiments, and new stuff over time.
